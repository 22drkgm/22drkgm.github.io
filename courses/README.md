# Course materials

Drop each course's materials in its own subfolder here, e.g.:

    courses/NESC103/        (Air Pollution)
    courses/ESD511/         (Aerosols in the Atmosphere)

Then add a page `courses/<code>/index.html` and link it from the matching
row in `teaching.html` (replace the "materials coming soon" note with
`<a class="materials" href="courses/<code>/index.html">Materials</a>`).
